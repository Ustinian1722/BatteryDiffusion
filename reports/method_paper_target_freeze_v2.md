# Method-paper target freeze v2

Date: 2026-09-12

This freeze is written **before inspecting the first architecture-benchmark scores**. It preserves the method-paper positioning from v1, but tightens one architectural point that was internally inconsistent in v1: continuous TTV and multi-horizon risk must be generated by the same event-time distribution rather than by two loosely coupled heads.

## Positioning

The paper is method-centric. RA-CDiff remains a supporting contribution for destructive-test scarcity and is not permitted to provide a hidden advantage in the main architecture table.

Primary benchmark: Virtual Vehicle TS0330 A-H, eight independent BAK N21700CG-50 destructive experiments with package-provided first `vent_gas` event labels.

Primary task:

- 120 s causal context;
- synchronized cell-case temperature + package pressure;
- target `0 < tau_to_first_vent <= 600 s`;
- maximum temperature anywhere in the causal input window <=150 C;
- experiment-level outer folds: one held-out test, one held-out validation experiment, six training experiments;
- training normalization fit on training experiments only.

## Proposed model

Working name: **LATH-Net — Lag-Aware Thermo-pressure Hazard Network**.

### M1. Modality-specific dual-timescale causal encoders

Temperature and pressure are encoded separately using a short-timescale branch and a dilated long-timescale branch. This is a supporting representation component, not a standalone novelty claim.

### M2. Dynamic lag-aware thermo-pressure alignment

For each time step, the thermal latent state is compared with a bank of pressure latent states shifted only from the causal past. The frozen lag bank is:

`{0, 2, 5, 10, 20, 30} s`.

A learned softmax over lags yields a time-varying aligned pressure precursor representation. This is stricter than one global lag weight per input window and is the main cross-modal mechanism.

### M3. Reliability-gated fusion

Aligned pressure features pass through a learned reliability gate conditioned jointly on temperature and aligned pressure. Fusion then uses complementary interaction terms (thermal state, gated pressure state, difference, and element-wise interaction). The purpose is to suppress apparatus-specific/noisy mechanical information while retaining precursor dynamics.

### M4. Unified discrete-time event-hazard head

The interval `(0, 600] s` is divided into 40 ordered bins of width 15 s. LATH-Net predicts conditional event hazards for bins 1-39; the final bin is forced to terminate the remaining survival mass so the resulting event-time probability distribution sums to one.

For bin k:

`q_k = S_{k-1} * h_k`, where `S_{k-1} = prod_{j<k}(1-h_j)`.

The cumulative pre-vent risk is:

`F_k = sum_{j<=k} q_j = 1-S_k`,

which is monotone by construction. Continuous time-to-vent is derived from the **same distribution** using its expected event time over bin midpoints. Therefore the model cannot independently output a low TTV and a contradictory low near-term event risk.

Training loss contains:

1. discrete event-time negative log likelihood;
2. Smooth-L1 loss on distribution-derived continuous TTV;
3. within-experiment event-progress ranking regularization.

The headline TTV estimate is distribution-derived; there is no independent direct regression head in the full model.

### M5. Event-progress ranking

Within each training experiment, windows separated by at least 60 s in true remaining time form ordered pairs. The later/closer-to-vent window should not be assigned a longer predicted TTV. Experiment identity is used only to construct training pairs and is never a predictor input.

## Main baselines

All baselines receive identical raw causal temperature+pressure windows and identical folds:

- CNN / 1D-CNN;
- LSTM;
- GRU;
- TCN;
- Transformer encoder;
- CNN-LSTM;
- Attention-GRU;
- TCN-Transformer.

The first benchmark run already launched under v1 remains an **exploratory architecture reconnaissance run**. Its baseline results may be retained if the input, folds, scaling and training protocol are identical, but its v1 LATH-Net result is not the frozen headline Proposed result because v1 used separate TTV and monotone-risk heads. Final Proposed results must use this v2 unified-hazard formulation.

## Predeclared ablations

The following variants are frozen before v2 scores:

- Full LATH-Net v2;
- `w/o Pressure`: temperature branch only;
- `w/o Dual-scale`: single-scale modality encoders;
- `w/o Lag alignment`: synchronous pressure-temperature fusion only;
- `w/o Reliability gate`: aligned pressure fused without learned reliability gating;
- `Direct regression`: replace unified hazard distribution with a direct scalar TTV head;
- `w/o Progress ranking`: remove pairwise event-order loss.

For mechanism attribution, lag-weight distributions and reliability-gate values will be summarized versus time-to-vent, but these diagnostics are not used for model selection.

## Metrics

Headline architecture metrics, aggregated at independent held-out experiment level:

- MAE (s);
- RMSE (s);
- MedAE (s);
- R2;
- worst-held-out-experiment MAE.

Hazard-quality metrics for LATH-Net and hazard-compatible variants:

- AUROC/AUPRC at 60, 120, 180, 300 and 450 s horizons;
- Brier score at the same horizons;
- cumulative-risk monotonicity violations (must be exactly zero by construction for Full);
- warning lead-time / false-alarm analysis under a threshold selected using training/validation data only.

Parameter count and inference latency are reported as engineering diagnostics, not accuracy metrics.

## RA-CDiff placement

Only after the architecture is frozen:

- LATH-Net + real only;
- LATH-Net + anchor-matched classical augmentation;
- LATH-Net + RA-CDiff.

The main architecture comparison remains real-only for every model.

## Evidence hierarchy

1. LATH-Net v2 versus standard and strong hybrid baselines on real-only experiment-level TTV prediction.
2. Ablation evidence that lag alignment, reliability gating, unified hazard modeling and progress ranking are individually useful in aggregate.
3. Multi-horizon warning consistency and interpretation of learned precursor lags.
4. RA-CDiff as a secondary scarcity-training contribution.
5. External/domain-shift validation on independent real experiments without retuning.

## Strategic stop condition

Continue development without user intervention unless the full v2 model fails to beat strong baselines after reasonable predeclared optimization, or the core lag/hazard modules fail aggregate ablation. Those outcomes would require reconsidering the paper's method claim.
