# Virtual Vehicle time-to-vent augmentation protocol

Date: 2026-09-12

This protocol is frozen after the real-only time-to-vent baseline and before any augmentation score for the regression task is computed.

## 1. Question

The secondary question is not whether RA-CDiff can make visually plausible curves. It is:

> **When only two real destructive experiments are available, can local RA-CDiff variants improve prediction of remaining time to the first `vent_gas` event on a third unseen real experiment?**

## 2. Frozen regression task

Inherited unchanged from `reports/virtual_vehicle_time_to_vent_protocol_freeze.md`:

- independent experiments: TS0330A–H;
- causal context: 120 s;
- stride: 10 s;
- event: first package-provided `vent_gas` marker;
- target: `tau = t_event - t_window_end`;
- retain only `0 < tau <= 600 s`;
- max temperature within input window: <=150 C;
- no post-event samples;
- interpolation only inside measured support.

## 3. Scarcity folds

Use exactly the same 24 predeclared k=2 experiment pairs used by the primary early-warning augmentation study: three training pairs for each of eight held-out real experiments.

The held-out experiment is selected before normalization, generator fitting, augmentation, or predictor fitting.

## 4. Continuous-label preservation rule

A synthetic time-series window does not create a new event time. Therefore no synthetic `tau` is estimated from the generated signal and no event time is hallucinated.

RA-CDiff remains **real anchored**. Each synthetic candidate is generated by perturbing/denoising one real training anchor window without shifting or warping its time axis. The synthetic sample inherits exactly the anchor's observed event-relative label:

`tau_synthetic = tau_real_anchor`.

This is the same label-preservation assumption used in local jitter/scaling augmentation, but applied through conditional diffusion. It is valid only because temporal position is unchanged.

## 5. Generator conditioning

The fixed three-stage embedding in RA-CDiff is repurposed only as a local regression-conditioning aid. For each training pair:

1. compute the 1/3 and 2/3 quantiles of **training-fold real tau only**;
2. assign each real training window to early/middle/late `tau` tertile 0/1/2;
3. condition RA-CDiff on this training-fold tertile.

The tertile boundaries are never computed from the held-out experiment. Tertiles are used only to keep local synthetic dynamics associated with similar remaining-time regimes; the regression target remains the continuous anchor `tau`.

## 6. Exactly anchor-matched classical comparator

For every retained RA-CDiff synthetic window, classical augmentation receives the **same real anchor index** and therefore the same inherited `tau` label. It applies the same baseline-preserving local amplitude/noise transform used in the earlier comparator.

Thus RA-CDiff and classical have, fold by fold:

- identical synthetic count;
- identical real-anchor distribution;
- identical continuous target-label distribution.

This is stricter than merely matching total augmentation count.

## 7. Synthetic budget and screening

The existing RA-CDiff distribution/novelty quality gate remains unchanged. Additional task guards:

- finite values only;
- generated maximum temperature <=150 C;
- retained synthetic count <= number of real training windows;
- if a budget cap is required, sampling is balanced across the three training-fold tau tertiles.

Synthetic samples remain local training variants and never increase independent experimental n.

## 8. Predictor and representations

The already frozen regression models remain unchanged:

- headline model: StandardScaler + HuberRegressor(epsilon=1.35, alpha=1e-4, max_iter=3000);
- secondary nonlinear diagnostic: RandomForestRegressor(n_estimators=300, max_depth=5, min_samples_leaf=3, random_state=2026).

Representations remain:

- temperature;
- pressure_absolute;
- pressure_shape;
- fusion_absolute;
- fusion_shape.

For the **augmentation-method comparison**, `fusion_absolute` is the predeclared headline representation because RA-CDiff is a multimodal augmentation method and this is the same fusion interface used by the primary warning task. This choice is methodological and is frozen despite the real-only Huber temperature representation having the lower MAE in the already archived baseline.

## 9. Evaluation and decision rule

Metrics are first averaged across the three predeclared training pairs for each held-out experiment and then macro-averaged over `n=8` real held-out experiments.

Headline metric: MAE in seconds. RMSE and median absolute error are secondary.

Paired contrasts on `fusion_absolute` Huber:

- RA-CDiff vs real-only;
- anchor-matched classical vs real-only;
- RA-CDiff vs anchor-matched classical.

Report mean paired delta MAE, 95% experiment-bootstrap CI, number of held-out experiments improved, and exact sign-flip p-value.

A claim that augmentation improves time-to-vent estimation requires a negative mean delta MAE and a 95% experiment-bootstrap interval excluding zero for the corresponding contrast. Otherwise the result is retained as mixed/negative evidence.
