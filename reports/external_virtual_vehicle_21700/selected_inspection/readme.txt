Content of this repository:

Results of 8 Thermal Runaway Experiments with the cell type: BAK N21700CG-50

# Test Organisation:
The Experiments include 8 cells which are tested in Experiments with index A through H.
Each experiment A,...,H is assembled inside its own sample-holder called tower.
The Towers come in 4 pairs, named AB, CD, DF, GH and contain respective cell A...H.


# Directory structure:
  * report_BAK_N21700CG-50_60SOC_TS0330.pdf: full Report of all 8 experiments
  * report_BAK_N21700CG-50_60SOC_TS0330.xlsx: overview table of the Experiment results
Fotos_videos:
  * subfolders for cells A,...,H including Fotos before and after the Thermal Runaway
  * Tower Setups AB...GH, including Fotos before and after the Thermal Runaway
Plots_and_raw_data: Experiments A … H, each containing:
  * generated plots
  * compiled_data2_TS0330X.zip: raw data in matlab Format, zipped
  * export_TS0330X.xlsx: raw data, compressed in excel-CSV Format
  * Zxxx_01_TS0330_MPo_Channel_1_Wb_1.xlsx: Cycling data of cycling the cell prior to TR test.
